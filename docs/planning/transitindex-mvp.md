## Vision

### The sharpened thesis
TransitIndex is not a data directory; it is **sourced accountability ammunition**. The
live job: a councillor aide, advocate, or transit-beat journalist needs a credible,
cite-able number to win a public argument. The source link is the feature, because
ammunition is worthless if the other side can dispute the number. This retro-justifies
the provenance obsession.

### The one unknown the MVP exists to test
Will a civically-engaged individual pay ~$20/year for an episodic need when StatCan and
Google are free? No one has paid or asked yet. The MVP is a live payment test, not a
finished product. Kill/scale line (from the design doc): of the first 10 buyers
personally approached, >=3 pay -> scale the PDF treadmill; 0-2 pay -> pivot to a
free-public model (Approach C) or stop.

## Accepted Scope — Milestone 1 (revenue-capable, ships first)
- Structured adapters, real data, auto-ingested: StatCan 23-10-0307 (ridership + revenue,
  **7 of 10** agencies — TTC, STM, TransLink, Calgary, Edmonton, Metrolinx@GTHA,
  BC Transit@Victoria-only; Metrolinx row = GO+UP Express network; NOT OC Transpo/MiWay/
  Burlington), Edmonton/Calgary open data,
  TransLink/Metrolinx quarterly.
- Free, SEO-indexable directory of all Canadian agencies; "fundamentals pending" long tail.
- Sourced fundamentals pages, per-metric "as of" dates.
- **Free/paid split:** FREE = ordinal RANK ("Ranked 3rd of 10") + attribution notice (no
  number, no deep-link). PAID = rank + raw number + clickable provenance. Rank, not
  percentile. Rank vs ALL agencies by default; typology/geographic filters are PAID.
- Identity: free browsing needs NO login; paying requires an account (signup/Google OAuth)
  with Stripe linked to it.
- Metered $20/yr Stripe gate, cookie soft-meter, SEO-safe.
- [ACCEPTED] Gate conversion instrumentation, source-feed health alert, request-this-agency.

## Accepted Scope — Milestone 2 (behind M1)
- LLM PDF extractor + validation/flagging + `pending_values` staging + human review queue
  (FastAPI). Gold-fixture eval as the quality bar + regression guard.

## Explicitly NOT in scope (deferred)

- Full accounts / watchlist / dashboard -> Phase 3 (paid-path account slice is in M1).
- US / NTD ingestion -> schema absorbs it with zero change, but no build.
- Bounding-box provenance deep-links (~2x ingestion cost).
