Data flow · TransitIndex

Ingest pipeline — every number is staged before it is real

Trust tiers

  • Tier 0 (StatCan · NTD · Hamilton open data) auto-approves only when validation raises zero flags
  • Tier 2 (PDF extraction) always lands as pending — a human approves every value
  • Every batch writes a feed_runs health row

Bulk path

  • One transaction per feed, guarded by pg_advisory_xact_lock
  • Diff-aware: absent → insert · changed → supersede · identical → skip
  • --reset wipes only that feed's provenance, dry-run first

Derived layer

  • Monthly → annual / YTD rollups (period_rollup)
  • Equation solver runs to fixpoint, records lineage
  • Ranks for all + subdivision cohorts; CAD→USD inside the rank job only
