System architecture — web reads, ingest writes

Read path

  • force-dynamic RSC pages → server/data + metrics/access
  • metrics/queries.ts is the only module allowed to read core.metric_values (ESLint-enforced)
  • Connects as web_reader — SELECT-only on core
  • Viewing is free; the sole paywall is the CSV download route

Auth & billing

  • NextAuth v5, database sessions in app.sessions
  • Google + Resend magic-link providers
  • Stripe webhook is the sole writer of subscription_status
  • Download route: no session → sign-in · not paid → 403

Write path

  • All core.* writes go through the ingest CLI
  • Feeds auto-approve at tier 0; PDFs always human-reviewed
  • Promotion enforces one_current_value + audit rows
  • Ranks + derived values recompute after promotion
